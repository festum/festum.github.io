Privacy Policy

This policy covers Font Rendering Enhancer, a Chrome extension that adjusts font stroke and shadow rendering on web pages (Chrome Web Store item ID hmbmmdjlcdediglgfcdkhinjdelkiock). It explains what data the extension handles and how.

Summary

  • The extension stores the display settings you choose.
  • It does not collect, transmit, or sell personal data.
  • It contains no analytics, no advertising, no telemetry, and no remotely loaded code.
  • Page content, browsing history, and the addresses you visit never leave your browser.

Data the extension stores

The extension stores only the settings you configure in its options page and popup:

  • stroke and shadow — the global rendering values.
  • sites — per-site overrides you create. Each entry holds the domain name of the site together with the values you set for it. A domain name is stored only for sites where you choose to add an override.

These are the only values written to storage. They are kept in the chrome.storage.sync area, which is Chrome's storage for extension settings. If you have Chrome sync enabled, Chrome keeps them in your Google Account so they carry over to other browsers you are signed into; if sync is disabled, they remain on the local device. Either way the settings belong to your Chrome profile, and the developer cannot read them.

Data the extension does not collect

The extension does not collect, store, or transmit:

  • Browsing history, or the full addresses of pages you open.
  • The content of the pages you view.
  • Form entries, passwords, or files.
  • Your identity, location, or device details.
  • Usage statistics, crash reports, or diagnostics.

To decide whether an override applies, the extension reads the domain name of the page you are on. That domain is used in memory to look up your settings and is not recorded, except when you deliberately add an override for that site, in which case the domain is stored as described above. The full addresses of the pages you visit are never read or stored.

The extension makes no network requests. Nothing is sent to the developer or to any third party, and nothing is sold or shared for advertising or any other purpose. All processing happens locally in your browser.

Permissions and why they are needed

  • storage — to read and write the settings described above.
  • <all_urls> host permission — to inject the extension's stylesheet into the pages you visit, which is what makes the rendering adjustment apply. The extension writes CSS custom properties on the page; it does not read, record, or upload page content.

Sharing with third parties

The extension shares no data with any third party. The only other party involved is Google, which provides the Chrome browser and, when you enable Chrome sync, stores the settings in your Google Account under Google's own privacy policy. The developer has no access to that storage.

Retention and deletion

Your settings remain until you change or remove them. To delete them:

  • In the extension's options page, use Reset to defaults to clear the global values, or remove a per-site entry to clear that override.
  • Removing the extension from Chrome deletes the settings Chrome holds for it.

If Chrome sync is enabled, Chrome propagates the deletion to the browsers you are signed into.

Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
